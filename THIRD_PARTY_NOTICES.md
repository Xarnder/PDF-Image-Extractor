# Third-party dependencies

The exact installed base Python versions are recorded in `backend/requirements.lock`; frontend versions and integrity checks are in `frontend/package-lock.json`.

| Dependency | Purpose | Upstream license |
| --- | --- | --- |
| PyMuPDF / MuPDF | PDF parsing, placement inspection, rendering | AGPL-3.0 or commercial license |
| FastAPI, Starlette, Uvicorn, Pydantic | Local API and validation | MIT / BSD as specified upstream |
| Svelte, Vite, TypeScript | Local frontend build and UI | MIT / Apache-2.0 |
| Lucide icons | Interface icons | ISC |
| OpenCV | Raster layout analysis | Apache-2.0 |
| NumPy, SciPy, PyWavelets | Numerical/image hash calculations | BSD-style |
| Pillow | Image decoding and export | HPND / MIT-CMU |
| ImageHash | Perceptual hashes | BSD-2-Clause |
| psutil | Worker resource monitoring | BSD-3-Clause |
| pytest, Vitest, httpx, ReportLab | Test and fixture tooling | Upstream MIT/BSD-style licenses |
| Optional PyTorch / torchvision | Local inference | BSD-style |
| Optional Transformers / Heron weights | Document layout detection | Apache-2.0 |

Refer to each installed package's metadata/license files for authoritative license text and transitive dependencies. PyMuPDF's official [license page](https://pymupdf.io/licensing) explains its dual-license options. This source checkout does not grant a commercial PyMuPDF license or remove upstream redistribution obligations.

The synthetic PDF test assets are generated by this project's fixture code. No third-party photographs are bundled. The user-provided interface screenshot is used only as a design reference and is not redistributed with the application.
